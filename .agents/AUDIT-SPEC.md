## 1. 级别定义（先定级，再输出；跨次执行保持同一标尺）

| 级别 | 定义 | 典型判据 |
|---|---|---|
| P0 阻断 | 可致资损 / 数据丢失 / 安全暴露 / 生产故障 | 硬编码凭据、注入、越权、破坏性副作用 |
| P1 高危 | 逻辑错误或显著性能劣化 | 条件反转、并发击穿、N+1 慢查、句柄泄漏 |
| P2 中危 | 坏味道 / 低效 / 维护性隐患 | 死代码、重复逻辑、过时注释误导 |
| P3 建议 | 风格与可读性改进 | 命名、结构建议，不改变行为 |

## 2. 扫描范围

默认全仓库；用户指定目录 / 模块时以指定为准。输出问题清单前，先报告扫描范围与文件总数。

## 3. 扫描四大实战靶心 (只报有确凿证据的问题)

每条发现必须提供：`文件:行号` + 判定依据。**误报比漏报更有害，无证据推测一律丢弃。**
证据不足的灰区发现须标注置信度（**确凿 / 疑似**）：疑似项禁止定级 P0 / P1，只能丢弃或以低置信度备注列出。

### 🎯 靶心一：冗余资产与死代码 (Hygiene)
- **扫什么**：零引用源文件；近重名历史备份（`*.bak`, `*_v2`）；未调用的内部函数/导出符号；声明但全库无调用的外部包；调试残留（`console.log` / `print` / `debugger`、无出处裸 TODO、注释掉的代码块；CLI 程序合法 stdout 除外）。
- **不算问题**：动态反射/约定路由引用的文件；测试夹具与样例；对外发布的公共 API；类型包与构建插件。

### 🎯 靶心二：逻辑缺陷与并发暗病 (Logic & Concurrency)
- **扫什么**：条件反转、边界 off-by-one；未 await 的异步 Promise；共享可变状态在并发下的读写交错；重复执行产生破坏性副作用（幂等击穿）。
- **不算问题**：纯粹代码行数长但逻辑正确的代码；已有互斥锁或防抖保护的并发。

### 🎯 靶心三：安全防线与敏感泄露 (Security & Secrets)
- **扫什么**：硬编码 API Key/Token/私钥；明文密码/敏感个人数据入日志；SQL/命令拼接注入；路径穿越；水平越权。
- **判据标准**：敏感字段**值出现才算**，仅字段名声明不算泄露；使用框架参数化绑定的不算注入。

### 🎯 靶心四：性能内耗与资源泄漏 (Performance & Resources)
- **扫什么**：循环内发起数据库查询（N+1 慢查）；打开未关闭的连接/文件句柄；外部网络调用缺乏超时（Timeout）与重试退避。
- **不算问题**：已使用语言自动释放机制（`with` / `defer` / `try-with-resources`）的资源。

按 P0（阻断）➔ P1（高危）➔ P2（中危）➔ P3（建议）排序，级别判定依据见第 1 节。

| ID | 位置 (文件:行号) | 靶心分类 | 级别 | 问题描述 | 判定证据 (调用链/输出/反例) | 最小修复建议 | 验证命令 |
|---|---|---|---|---|---|---|---|
| A-01 | `src/auth.ts:42` | 安全-凭据 | P0 | 硬编码 JWT 密钥 | 字符串字面量显式赋值 | 改为读取环境变量 | `npm test` |
